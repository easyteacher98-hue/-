# 🔔 보드게임천국 (과일 딩동 · 세계여행 마블 3D)

모둠원이 각자 기기(노트북·태블릿·휴대폰)로 접속해 함께 즐기는 **실시간 보드게임 사이트**입니다.
여러 선생님이 같은 사이트를 함께 써도 **반(교실)마다 1~6모둠이 따로** 열려 서로 섞이지 않습니다.

- **교사용 화면에서 우리 반 만들기**: 첫 화면 하단의 **[교사용]** 링크(또는 `#/teacher`)로 들어가 **교사 개설 암호**와 반 이름·**교사 비밀번호(PIN)** 를 넣으면 반 코드와 **우리 반 전용 링크**(`?class=반코드`)가 발급됩니다. (학생 첫 화면에는 반 만들기 카드가 없습니다)
- **반 코드로 입장**: 학생은 반 코드(또는 전용 링크)로 들어와 **이름 대신 출석번호(1~99)** 와 자기 모둠만 고르면 바로 입장합니다.
- **반별 독립 공간**: 반 코드마다 1~6모둠 방과 교사 관전 공간이 따로 있어 다른 반 학생·모둠과 절대 섞이지 않습니다.
- **교사 PIN 인증**: 그 반을 만든 때 정한 PIN을 아는 선생님만 교사 관전과 방 초기화를 할 수 있습니다.
- **우리 반 포인트 랭킹**: 한 판이 끝나면 순위대로 포인트가 쌓입니다. (1등 +100P·2등 +50P·3등 +30P·그 외 +10P, 1등은 승리 +1)
- **내 기록 저장**: 학생 브라우저에도 (반 코드 + 번호) 기준 승수·포인트가 저장되어 서버가 쉬어도 내 기록은 남습니다.
- **우승 축하 연출**: 최종 우승 시 컨페티·박수/팡파레와 함께 **최종 순위 팝업**(순위·아바타·번호·남은 카드·종 성공/실수·포인트)이 뜹니다.
- **노트북 화면에 꽉 차게**: 넓은 화면에서는 게임판·카드·종이 큼직하게 펼쳐지고, 모바일 레이아웃은 그대로 유지됩니다.
- **두 가지 게임**: 🔔 **과일 딩동**(순발력)·🎲 **세계여행 마블 (3D)**(주사위·도시 매입·건물). 6개 모둠이 각자 방에서 동시에 즐깁니다.
- **6개 모둠 방**: 1모둠 ~ 6모둠 (모둠당 4명 기준, `GROUP_CAPACITY` 로 변경 가능).
- **실시간 멀티플레이**: 방장이 시작하면 카드 뒤집기와 종 치기가 서버에서 동시에 판정됩니다.
- **귀여운 파스텔 디자인**: 크림·파스텔 색, 둥근 카드와 도톰한 버튼, 표정 있는 과일 그림, **번호별 동물 아바타**(강아지·고양이·토끼·곰·여우·병아리).
- **종소리와 반짝임**: 종을 치면 흔들리는 애니메이션과 Web Audio 종소리, 정답/오답 색 피드백. **[🔔 소리]** 버튼으로 음소거할 수 있습니다.
- **교사 관전 모드**: 우리 반 6개 모둠의 상태(대기/진행/종료), 참여 학생, 남은 카드, 현재 차례, 최근 이벤트를 한눈에 보고 원하는 모둠을 관전합니다. (관전자는 조작 불가, 막힌 방은 **[🧹 방 초기화]**)
- **방 나가기 · 게임 종료**: 게임판 위 **[🚪 방 나가기]** 로 실제 퇴장, 방장은 **[⏹ 게임 종료]** 로 대기실 복귀.
- **다시 들어가기**: 모둠 목록으로 나와도 내 자리는 남아 있어 로비 카드의 **[다시 들어가기]** 로 바로 복귀합니다.
- **AI 봇 연습**: 서버에 접속하지 않아도 혼자서 4~5인 게임을 바로 해 볼 수 있습니다.
- **게임 규칙 안내**: 입장 화면과 대기방, 게임판 어디서나 규칙 모달을 열 수 있습니다.
- **폰트**: 제목·버튼은 배민 주아체(`Jua`), 본문은 고운돋움(`Gowun Dodum`) — 둘 다 OFL 무료 폰트이며, 폰트를 못 받아오는 오프라인 환경에서는 시스템 둥근 고딕으로 대체됩니다.
- 하단에 작은 **Made by easy** 크레딧이 있습니다.

## 1. 실행 방법

Node.js 18 이상이 필요합니다.

```bash
cd halligalli-web
npm install        # 의존성 설치 (ws, jsdom(개발용))
npm start          # 서버 실행 (기본 포트 3000)
```

실행하면 터미널에 주소가 나옵니다.

```
내 컴퓨터 :  http://localhost:3000
같은 와이파이(모둠원) :  http://192.168.0.10:3000
```

학생 기기에서는 **같은 와이파이(같은 공유기)에 연결한 뒤** 두 번째 주소로 접속합니다.
포트를 바꾸려면 `PORT=4000 npm start`, 모둠 정원을 바꾸려면 `GROUP_CAPACITY=5 npm start` 처럼 실행합니다.
반 목록을 저장할 파일 위치는 `CLASS_STORE=/경로/classes.json` 으로 바꿀 수 있습니다(기본 `data/classes.json`).

> 선생님 PC에서 서버를 켠 채로 수업이 끝날 때까지 두면 됩니다. 종료는 `Ctrl+C`.

### 인터넷이 없는 교실에서

`public/index.html` 파일을 브라우저로 직접 열어도 **AI 봇 연습**과 규칙 안내는 그대로 동작합니다.
(모둠 대전은 서버가 필요합니다.)

## 2. 수업에서 이렇게 사용합니다

1. **선생님**: 서버 주소로 접속 → 첫 화면 하단의 **[교사용]** 링크(또는 주소 끝 `#/teacher`) →
   **교사 개설 암호**와 반 이름(예: `3학년 2반`), 반 코드(비워 두면 자동), **교사 비밀번호(PIN, 숫자 4~8자리)** 를 넣고 **[우리 반 만들기]**.
   - 반 코드와 **학생용 링크**(`https://주소/?class=반코드`)가 나옵니다. **[🔗 학생용 링크 복사]** 로 카톡에 붙여 보내세요.
   - 같은 사이트 주소를 다른 선생님께 보내면, 그 선생님도 자기 반을 따로 만들어 쓸 수 있습니다.
2. **학생**: 링크를 열거나 첫 화면 **[🎒 학생 · 반 코드로 입장]** 에 반 코드를 넣습니다.
   → **우리 반 게임 선택** 화면이 열립니다.
3. 학생: **과일 딩동** 또는 **세계여행 마블 (3D)** → **출석번호(1~99)** 입력 → 자기 **모둠(1~6모둠)** 클릭 → 대기방 입장.
4. 대기방에서 친구들이 모이면 방장이 **[▶ 게임 시작]** 을 누릅니다.
   - 모둠원이 부족하면 **[🤖 봇 추가]** 로 인원을 채워 바로 시작할 수 있습니다.
   - **[📖 게임 규칙 보기]** 로 규칙을 함께 확인하세요.
5. **선생님**: 우리 반 화면의 **[👩‍🏫 선생님 모드]** → 교사 PIN 입력 → 6개 모둠 현황 확인 → **[👀 관전하기]** 로 특정 모둠 게임판을 실시간 관전.
6. 게임이 끝나면 **컨페티·박수와 함께 최종 순위 팝업**이 뜹니다. 방장은 **[한 판 더 (다시 시작)]**, 학생은 **[방 나가기]** 로 정리합니다.
   - 순위 포인트는 **우리 반 포인트 랭킹**(반 화면·대기방·교사 관전)에 쌓이고, 내 승수·포인트는 이 기기에도 저장됩니다.
7. 방장은 게임 중 **[⏹ 게임 종료]** 로 대기실로 돌아갈 수 있고, 선생님은 교사 관전 화면의 **[🧹 방 초기화]**(PIN 인증 필요)로 막힌 방을 정리할 수 있습니다.

> 브라우저 탭을 그냥 닫거나 와이파이가 끊긴 경우는 '나가기'와 다릅니다. 그 학생은 자동 플레이로 남아 게임이 멈추지 않고, 새로고침하면 원래 자리로 돌아옵니다.

### 조작

| 동작 | 방법 |
| --- | --- |
| 카드 뒤집기 | **[카드 뒤집기]** 버튼 또는 **F 키** (내 차례에만) |
| 종 치기 | 가운데 **🔔 종** 버튼 또는 **스페이스바** |
| 과일 합계 확인 | **[합계 보기]** (연습·지도용, 기본 꺼짐) |
| 소리 켜기/끄기 | **[🔔 소리 / 🔕 무음]** |
| 방 나가기 | **[🚪 방 나가기]** (게임 중에는 한 번 확인) |
| 게임 종료(방장) | **[⏹ 게임 종료]** → 확인 |
| 규칙 보기 | **[📖 규칙]** |

## 3. 과일 딩동 규칙 (구현된 정식 규칙)

- **카드 56장**: 과일 4종(딸기·바나나·라임·자두) × [1개 5장, 2개 3장, 3개 3장, 4개 2장, 5개 1장] → 과일당 14장
- 카드를 인원수(2~5명)에 맞춰 최대 1장 차이로 똑같이 나눕니다.
- 자기 차례에 자기 덱 맨 위 카드를 자기 앞에 1장 뒤집습니다. (차례는 자동으로 넘어갑니다)
- 테이블에 보이는 **모든 사람의 맨 위 카드**의 과일 개수를 합쳐, **어떤 과일이든 정확히 5개**가 되면 종을 칩니다.
- 가장 먼저 종을 친 사람이 **테이블에 공개된 카드를 모두** 가져갑니다. (덱 맨 아래에 섞여 들어감)
- 5개가 아닌데 종을 치면 **다른 모든 플레이어에게 내 카드 1장씩** 줍니다.
- 덱과 공개 카드가 모두 없어지면 탈락, **마지막 1인이 우승**합니다.
  - 방장이 **[2명 남았을 때 게임 종료]** 를 켜면 두 명이 남는 순간 카드가 많은 사람이 우승합니다.

연타 방지를 위해 종을 친 직후 0.5~0.7초 동안은 다시 칠 수 없습니다.

## 4. 세계여행 마블 (3D) 규칙

도시를 사고 건물을 세워 통행료를 받는 **모두의마블 스타일 3D 보드게임**입니다. 서버가 주사위를 굴리고 판정하며, 화면은 3D로 결과를 연출합니다.

- **보드**: 28칸 (출발 · 도시 15 · 황금열쇠 4 · 세금 3 · 보너스 2 · 무인도 · 세계여행 · 무료주차)
- **인원**: 2~4명, 시작 자금 120만원, 출발지 통과 월급 20만원
- **매입/건설**: 도시 칸에 멈추면 매입, 내 도시에 다시 멈추면 **별장 → 빌딩 → 호텔**로 업그레이드
- **통행료**: 건물 단계에 따라 도시 가격의 10% · 25% · 50% · 90%
- **주사위**: 더블이면 한 번 더, **3연속 더블은 무인도행**
- **무인도**: 더블로 탈출하거나 3번 실패 후 보석금 15만원
- **황금열쇠**: 은행 이자·복권·생일 축하·기부·세무 조사·출발지 이동·무인도행 등 12장
- **파산**: 통행료를 낼 수 없으면 파산하고 도시는 채권자(또는 은행)에게 넘어갑니다
- **종료**: **15라운드**(대기방에서 10·15·20라운드로 변경)가 지나면 **총자산(현금+도시+건물)** 순위로 우승, 한 명만 남아도 종료

### 3D 보드 조작

- 보드를 **드래그**하면 시점이 돌아가고, **휠(또는 두 손가락)** 로 확대·축소합니다. **[🎥 시점 초기화]** 로 처음 시점으로 돌아옵니다.
- 주사위 2개가 중앙에서 굴러가 **서버가 정한 눈에 정확히 맞춰** 멈춥니다.
- 말은 **출석번호의 동물 색**을 그대로 쓰고, 칸을 하나씩 통통 튀며 이동합니다.
- 3D(WebGL)를 쓸 수 없는 기기에서는 같은 게임을 **2D 보드**로 보여 주므로 그대로 플레이할 수 있습니다.

## 5. 파일 구조

```
halligalli-web/
├── server.js                 # HTTP 정적 서버 + WebSocket 반/방/좌석/관전 서버 (게임 공통)
├── render.yaml               # Render 배포 설정 (npm install --omit=dev → 운영 의존성만 설치)
├── package.json
├── README.md
├── data/classes.json         # 만든 반 목록 (자동 생성, git에는 올리지 않음)
├── public/
│   ├── index.html            # 앱 셸
│   ├── engine.js             # ★ 과일 딩동 규칙 엔진 (서버 Node.js와 브라우저가 함께 사용)
│   ├── bluemarble-engine.js  # ★ 세계여행 마블 규칙 엔진 (서버 권위 · 주사위/매입/건설/무인도/황금열쇠)
│   ├── vendor/three.min.js   # 3D 보드용 Three.js (인터넷이 느려도 바로 뜨도록 로컬 포함)
│   ├── css/style.css         # 전체 스타일 (모바일·노트북 반응형)
│   └── js/
│       ├── app.js            # 라우터, ?class= 링크, 반/번호 저장, 토스트, 모달
│       ├── net.js            # WebSocket 연결/자동 재접속
│       ├── cards.js          # 표정 있는 과일 SVG·카드 렌더링
│       ├── avatars.js        # 번호별 귀여운 동물 아바타 SVG
│       ├── sound.js          # Web Audio 종소리·박수·팡파레 (음소거 기억)
│       ├── portal.js         # 첫 화면(우리 반 만들기·반 코드 입장)과 우리 반 게임 포털
│       ├── halligalli.js     # 과일 딩동 화면(번호 입장·대기방·게임판·결과 팝업·교사 관전·봇 연습)
│       ├── bluemarble3d.js   # 3D 보드 렌더러(캔버스 타일 텍스처·건물·주사위·말·카메라)
│       └── bluemarble.js     # 세계여행 마블 화면(입장·대기방·3D 게임판·관전·봇 연습)
├── src/
│   └── games/
│       ├── index.js          # 게임 레지스트리 (새 게임 등록)
│       ├── halligalli.js     # 과일 딩동 서버 모듈 (표준 게임 인터페이스)
│       └── bluemarble.js     # 세계여행 마블 서버 모듈 (표준 게임 인터페이스)

    ├── server.test.js        # WebSocket 방/관전/판정 통합 테스트
    ├── class.test.js         # 반 생성·반별 격리·교사 PIN·출석번호·포인트 적립 테스트
    ├── ui.test.js            # jsdom 화면 테스트 (첫 화면→교사용 반 만들기→번호 입장→게임→결과→교사 PIN)
    ├── bluemarble-engine.test.js  # 세계여행 마블 규칙(매입/건설/통행료/더블/무인도/황금열쇠/파산/라운드)
    ├── bluemarble-server.test.js  # 세계여행 마블 서버 판정·결과 포인트·교사 관전/초기화
    ├── bluemarble-ui.test.js      # 세계여행 마블 화면(3D/2D 보드·주사위·매입·봇 연습)
    └── offline.test.js       # 서버 없는 정적 호스팅 재접속 테스트
```

규칙 계산은 **한 파일(`public/engine.js`)** 에만 있습니다. 서버(멀티플레이 판정)와 브라우저(AI 봇 연습, 화면 표시)가 같은 코드를 쓰므로 규칙이 어긋나지 않습니다.

## 7. 새 게임 추가하기 (확장 구조)

1. `src/games/<game>.js` 에 표준 인터페이스를 구현합니다 (`src/games/halligalli.js` 참고):
   `id, title, emoji, status, minPlayers, maxPlayers, defaultRooms(), createGame(), applyAction(), botTick(), serialize(), summary(), reasonText()`
2. `src/games/index.js` 의 `registry` 배열에 등록합니다.
3. `public/js/<game>.js` 에 화면을 만들고 `BG.router.add(...)` 로 경로를 등록한 뒤, `public/index.html` 에 스크립트 한 줄을 추가합니다.
4. `public/js/portal.js` 의 `BG.portalGames` 에 게임 카드를 추가합니다.

서버의 반·방·좌석·관전·전송 로직(`server.js`)은 게임과 무관하게 동작하므로 고칠 필요가 없습니다.
윷놀이는 `src/games/index.js` 의 `planned` 목록에 "준비 중"으로 등록되어 있습니다.
반별 방은 게임 모듈의 `defaultRooms()` 를 반마다 새로 만들어 주므로, 새 게임도 자동으로 반마다 분리됩니다.

## 8. 서버 설정과 제한

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `HOST` | 0.0.0.0 | 바인딩 주소 |
| `GROUP_CAPACITY` | 4 | 모둠 방 정원 (최대 5) |
| `TEACHER_CREATE_CODE` | `easy` | 새 반을 만들 때 필요한 **교사 개설 암호**. 운영에서는 꼭 바꿔 주세요. |
| `CLASS_STORE` | `data/classes.json` | 만든 반(코드·이름·PIN 해시)을 저장하는 파일 |

- **반 목록은 파일에 저장**되어 서버를 다시 켜도 우리 반 링크가 살아 있습니다. PIN은 원문이 아니라 해시로만 저장합니다.
- **방 상태와 포인트 랭킹은 메모리에만** 보관합니다. 서버를 껐다 켜면 그 수업의 방과 **우리 반 포인트 랭킹은 초기화**됩니다. (학생 브라우저에 저장된 내 승수·포인트는 남습니다)
- **나가기**를 누르면 자리가 실제로 정리되고, 사람이 한 명도 남지 않으면 봇만 남은 방은 자동으로 대기 상태(0/인원)로 돌아갑니다.
- 게임 중 연결이 끊긴 학생은 **자동 플레이(AI)** 로 바뀌어 게임이 멈추지 않습니다. 같은 창에서 새로고침하면 원래 자리로 돌아옵니다(토큰 재접속).
- **교사 관전과 방 초기화는 반 PIN 인증이 필요합니다.** 학생은 자기 반 방에 참가한 상태로는 초기화할 수 없습니다.
- AI 봇 연습은 서버 없이도 되고, 우리 반 안에서도 그대로 쓸 수 있습니다.
- 동시 접속 인원은 서버 PC 성능에 따라 다르지만, 여러 반(반당 6모둠 × 4명 = 24명) 규모도 무리 없이 처리합니다.

## 9. 인터넷에 올려서 쓰기 (배포)

### 8-1. 정적 링크 — GitHub Pages (첫 화면 · AI 봇 연습 · 규칙 안내)

- 주소: **https://easyteacher98-hue.github.io/-/**
- `public/` 폴더의 정적 파일만 올라간 `gh-pages` 브랜치를 Pages 소스로 사용합니다.
- GitHub Pages는 **파일만 전달하는 정적 호스팅**이라 WebSocket 서버를 돌릴 수 없습니다. 그래서 이 링크에서는 **첫 화면·AI 봇 연습·규칙 안내만** 동작하고, 반 코드 입장과 모둠 실시간 대전은 아래 Render 서버 링크에서 합니다.
- `public/` 을 고친 뒤 사이트에 반영하려면 아래 명령 한 줄로 `gh-pages` 브랜치를 다시 만듭니다(1~2분 뒤 반영):
  ```bash
  bash scripts/deploy-pages.sh            # origin 의 gh-pages 로 배포
  bash scripts/deploy-pages.sh --dry-run  # 푸시 없이 결과만 확인
  ```

### 8-2. 실시간 멀티플레이 — Render 무료 서버

1. 아래 원클릭 링크로 Render에 로그인(저장소의 GitHub 계정으로 로그인)합니다.
   **https://render.com/deploy?repo=https://github.com/easyteacher98-hue/-**
2. Render가 저장소 루트의 `render.yaml` 을 읽어 무료 Node 웹 서비스를 만듭니다.
   (`npm install --omit=dev` → `npm start`, 헬스체크 `/health`) — 테스트용 `jsdom` 은 설치하지 않아 배포가 빠릅니다.
3. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소가 나옵니다. 이 주소 하나로 **반 만들기 + 반 코드 입장 + 6모둠 실시간 대전 + 교사 관전 + AI 봇 연습**이 모두 동작합니다. 학생 기기(노트북·태블릿·휴대폰)에 이 주소나 우리 반 링크를 알려 주세요.
4. 무료 플랜은 **15분간 접속이 없으면 서버가 잠들고**, 다시 접속하면 깨어나는 데 약 1분 걸립니다(그동안 로딩 화면). 수업 중에는 접속이 이어져서 잠들지 않습니다. 무료 인스턴스 시간은 한 달 750시간이고, 그 달치를 다 쓰면 다음 달 1일까지 무료 서비스가 멈춥니다.
5. 무료 플랜의 디스크는 임시라서, 서버가 새로 배포되면 `data/classes.json` 이 사라질 수 있습니다. 반 목록을 오래 보관하려면 유료 디스크를 붙이거나 `CLASS_STORE` 경로를 영구 저장소로 지정하세요.
