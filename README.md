# 🎲 보드게임천국 (13가지 교실 보드게임 · 반 코드 모둠 대전 · AI 봇 연습)

모둠원이 각자 기기(노트북·태블릿·휴대폰)로 접속해 함께 즐기는 **실시간 보드게임 사이트**입니다.
여러 선생님이 같은 사이트를 함께 써도 **반(교실)마다 1~6모둠이 따로** 열려 서로 섞이지 않습니다.

- **교사용 화면에서 우리 반 만들기**: 첫 화면 하단의 **[교사용]** 링크(또는 `#/teacher`)로 들어가 **교사 개설 암호**와 반 이름·**교사 비밀번호(PIN)** 를 넣으면 반 코드와 **우리 반 전용 링크**(`?class=반코드`)가 발급됩니다. (학생 첫 화면에는 반 만들기 카드가 없습니다)
- **반 코드로 입장**: 학생은 반 코드(또는 전용 링크)로 들어와 **출석번호(1~99)** 와 **이름**을 넣고 자기 모둠을 고르면 바로 입장합니다. 이름을 넣으면 `7번 김민수`처럼 보이고, 비워 두면 `7번`만 보입니다.
- **반별 독립 공간**: 반 코드마다 1~6모둠 방과 교사 관전 공간이 따로 있어 다른 반 학생·모둠과 절대 섞이지 않습니다.
- **교사 PIN 인증**: 그 반을 만든 때 정한 PIN을 아는 선생님만 교사 관전과 방 초기화를 할 수 있습니다.
- **우리 반 포인트 랭킹**: 한 판이 끝나면 순위대로 포인트가 쌓입니다. (1등 +100P·2등 +50P·3등 +30P·그 외 +10P, 1등은 승리 +1) 1인용 퍼즐은 **최고점을 갱신할 때** 점수에 따라 5~50P가 쌓입니다.
- **내 기록 저장**: 학생 브라우저에도 (반 코드 + 번호) 기준 승수·포인트가 저장되어 서버가 쉬어도 내 기록은 남습니다.
- **서버를 다시 켜도 남는 우리 반 기록(선택)**: `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN` 을 넣으면 반 목록(교사 PIN 해시)과 번호별 승수·포인트가 **Upstash 무료 Redis** 에 저장되어, Render 무료 서버가 잠들거나 다시 배포되어도 그대로 이어집니다. (설정하지 않으면 예전처럼 파일+메모리로 동작)
- **우승 축하 연출**: 최종 우승 시 컨페티·박수/팡파레와 함께 **최종 순위 팝업**(순위·아바타·번호·남은 카드·종 성공/실수·포인트)이 뜹니다.
- **노트북 화면에 꽉 차게**: 넓은 화면에서는 게임판·카드·종이 큼직하게 펼쳐지고, 모바일 레이아웃은 그대로 유지됩니다.
- **열세 가지 게임**: 🔔 **과일 딩동**(순발력)·🎲 **전국여행 마블 (3D)**(주사위·도시 매입·건물)·🎯 **숫자 줄세우기**(오름차순 줄 만들기)·⚫ **오목**(15x15 1:1)·🕵️ **라이어 추리게임**(힌트·투표)·🪵 **전통 윷놀이**(업기·잡기·지름길)·🔢 **숫자 타일 러미**(세트·런 만들기)·🃏 **도둑잡기**(짝 카드)·♟️ **전통 장기**(9×10)·🎨 **컬러 숫자 카드**(같은 색·숫자)·✏️ **선 긋기 땅따먹기**(사각형 완성)·🧩 **1인용 미니 퍼즐**(2048·짝맞추기)·🔢 **1인용 스도쿠**(4×4·6×6·9×9). 모둠 방은 게임마다 1~6모둠이 따로 열립니다.
- **학년별 추천 카테고리**: 포털에서 `전체 / 저학년 추천(1~2학년) / 중학년 추천(3~4학년) / 고학년 추천(5~6학년) / 1인용` 으로 골라 볼 수 있고, 카드마다 추천 학년·인원 배지가 붙습니다.
- **제작자 전용 통계(`#/admin`)**: 교사 개설 암호로 들어가 전체 반 수·학생 수·총 플레이·게임별 인기 순위·반별 현황을 봅니다. 학생 첫 화면에는 없고 교사용(`#/teacher`) 화면 아래 작은 링크로만 열립니다.
- **6개 모둠 방**: 1모둠 ~ 6모둠 (모둠당 4명 기준, `GROUP_CAPACITY` 로 변경 가능).
- **실시간 멀티플레이**: 방장이 시작하면 카드 뒤집기와 종 치기가 서버에서 동시에 판정됩니다.
- **귀여운 파스텔 디자인**: 크림·파스텔 색, 둥근 카드와 도톰한 버튼, 표정 있는 과일 그림, **번호별 동물 아바타**(강아지·고양이·토끼·곰·여우·병아리).
- **종소리와 반짝임**: 종을 치면 흔들리는 애니메이션과 Web Audio 종소리, 정답/오답 색 피드백. **[🔔 소리]** 버튼으로 음소거할 수 있습니다.
- **교사 PIN 입력**: 방 목록이 갱신되어도 입력하던 PIN이 지워지지 않고, **Enter 키**로도 확인됩니다. 6번 틀리면 1분만 잠기고 그 뒤에는 새로고침 없이 다시 시도할 수 있습니다. 전국여행 마블·미니게임 관전 화면에도 같은 PIN 확인 화면이 있습니다.
- **교사 관전 모드**: 우리 반 6개 모둠의 상태(대기/진행/종료), 참여 학생, 남은 카드, 현재 차례, 최근 이벤트를 한눈에 보고 원하는 모둠을 관전합니다. (관전자는 조작 불가, 막힌 방은 **[🧹 방 초기화]**)
- **방 나가기 · 게임 종료**: 게임판 위 **[🚪 방 나가기]** 로 실제 퇴장, 방장은 **[⏹ 게임 종료]** 로 대기실 복귀.
- **뒤로가기 자동 정리**: 방 나가기를 누르지 않고 **브라우저 뒤로가기**로 방 화면을 벗어나도 자동으로 방에서 나갑니다. 대기방에 '준비 중' 유령 인원이 남지 않고, 나온 친구는 같은 번호로 다시 들어올 수 있습니다. (새로고침·일시적 연결 끊김 뒤 재접속은 그대로 이어집니다)
- **방장 강퇴(내보내기)**: 인터넷이 끊겨 남은 자리나 겹쳐 들어온 친구를 방장이 내보냅니다. 대기방에서는 친구 자리 옆 **[🚪 내보내기]**, 게임 중에는 **[👥 참가자]** 창에서 내보냅니다. 내보낸 친구는 안내를 보고 모둠 선택으로 돌아가며, **같은 번호로 다시 들어올 수 있습니다**. 게임 중에 내보낸 자리는 AI가 이어서 플레이하므로 남은 친구들의 게임은 끊기지 않습니다.
- **다시 들어가기**: 모둠 목록으로 나와도 내 자리는 남아 있어 로비 카드의 **[다시 들어가기]** 로 바로 복귀합니다.
- **AI 봇 연습**: 서버에 접속하지 않아도 혼자서 4~5인 게임을 바로 해 볼 수 있습니다.
- **게임 규칙 안내**: 입장 화면과 대기방, 게임판 어디서나 규칙 모달을 열 수 있습니다.
- **폰트**: 제목·본문 모두 IBM Plex Sans KR — OFL 무료 폰트이며, 폰트를 못 받아오는 오프라인 환경에서는 시스템 고딕으로 대체됩니다.
- 하단에 작은 **Made by easy** 크레딧이 있습니다.

## 1. 실행 방법

Node.js 18 이상이 필요합니다.

```bash
cd halligalli-web
npm install        # 의존성 설치 (ws, jsdom(개발용))
npm start          # 서버 실행 (기본 포트 3000)
```

실행하면 터미널에 주소가 나옵니다.

```
내 컴퓨터 :  http://localhost:3000
같은 와이파이(모둠원) :  http://192.168.0.10:3000
```

학생 기기에서는 **같은 와이파이(같은 공유기)에 연결한 뒤** 두 번째 주소로 접속합니다.
포트를 바꾸려면 `PORT=4000 npm start`, 모둠 정원을 바꾸려면 `GROUP_CAPACITY=5 npm start` 처럼 실행합니다.
반 목록을 저장할 파일 위치는 `CLASS_STORE=/경로/classes.json` 으로 바꿀 수 있습니다(기본 `data/classes.json`).
서버를 다시 켜도 반 목록과 반별 랭킹을 그대로 두고 싶으면 `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN` 을 넣어 실행합니다(→ [8-3. Upstash Redis 영구 저장](#8-3-무료-영구-저장--upstash-redis-선택)).

> 선생님 PC에서 서버를 켠 채로 수업이 끝날 때까지 두면 됩니다. 종료는 `Ctrl+C`.

### 인터넷이 없는 교실에서

`public/index.html` 파일을 브라우저로 직접 열어도 **AI 봇 연습**과 규칙 안내는 그대로 동작합니다.
(모둠 대전은 서버가 필요합니다.)

## 2. 수업에서 이렇게 사용합니다

1. **선생님**: 서버 주소로 접속 → 첫 화면 하단의 **[교사용]** 링크(또는 주소 끝 `#/teacher`) →
   **교사 개설 암호**와 반 이름(예: `3학년 2반`), 반 코드(비워 두면 자동), **교사 비밀번호(PIN, 숫자 4~8자리)** 를 넣고 **[우리 반 만들기]**.
   - 반 코드와 **학생용 링크**(`https://주소/?class=반코드`)가 나옵니다. **[🔗 학생용 링크 복사]** 로 카톡에 붙여 보내세요.
   - 같은 사이트 주소를 다른 선생님께 보내면, 그 선생님도 자기 반을 따로 만들어 쓸 수 있습니다.
2. **학생**: 링크를 열거나 첫 화면 **[🎒 학생 · 반 코드로 입장]** 에 반 코드를 넣습니다.
   → **우리 반 게임 선택** 화면이 열립니다.
3. 학생: 게임 카드(과일 딩동 · 전국여행 마블 · 숫자 줄세우기 · 오목 · 라이어 · 윷놀이 · 숫자 타일 러미 · 도둑잡기 · 장기 · 컬러 숫자 카드 · 선 긋기 땅따먹기)를 고르고 **출석번호(1~99)** 와 **이름**(선택)을 입력 → 자기 **모둠(1~6모둠)** 클릭 → 대기방 입장. (1인용 퍼즐·스도쿠는 카드에서 바로 시작)
4. 대기방에서 친구들이 모이면 방장이 **[▶ 게임 시작]** 을 누릅니다.
   - 모둠원이 부족하면 **[🤖 봇 추가]** 로 인원을 채워 바로 시작할 수 있습니다.
   - **[📖 게임 규칙 보기]** 로 규칙을 함께 확인하세요.
5. **선생님**: 우리 반 화면의 **[👩‍🏫 선생님 모드]** → 교사 PIN 입력 → 6개 모둠 현황 확인 → **[👀 관전하기]** 로 특정 모둠 게임판을 실시간 관전.
6. 게임이 끝나면 **컨페티·박수와 함께 최종 순위 팝업**이 뜹니다. 방장은 **[한 판 더 (다시 시작)]**, 학생은 **[방 나가기]** 로 정리합니다.
   - 순위 포인트는 **우리 반 포인트 랭킹**(반 화면·대기방·교사 관전)에 쌓이고, 내 승수·포인트는 이 기기에도 저장됩니다.
7. 방장은 게임 중 **[⏹ 게임 종료]** 로 대기실로 돌아갈 수 있고, 선생님은 교사 관전 화면의 **[🧹 방 초기화]**(PIN 인증 필요)로 막힌 방을 정리할 수 있습니다.

> 브라우저 탭을 그냥 닫거나 와이파이가 끊긴 경우는 '나가기'와 다릅니다. 그 학생은 자동 플레이로 남아 게임이 멈추지 않고, 새로고침하면 원래 자리로 돌아옵니다.

## 3. 과일 딩동 규칙 (구현된 정식 규칙)

- **카드 56장**: 과일 4종(딸기·바나나·라임·자두) × [1개 5장, 2개 3장, 3개 3장, 4개 2장, 5개 1장] → 과일당 14장
- 카드를 인원수(2~5명)에 맞춰 최대 1장 차이로 똑같이 나눕니다.
- 자기 차례에 자기 덱 맨 위 카드를 자기 앞에 1장 뒤집습니다. (차례는 자동으로 넘어갑니다)
- 테이블에 보이는 **모든 사람의 맨 위 카드**의 과일 개수를 합쳐, **어떤 과일이든 정확히 5개**가 되면 종을 칩니다.
- 가장 먼저 종을 친 사람이 **테이블에 공개된 카드를 모두** 가져갑니다. (덱 맨 아래에 섞여 들어감)
- 5개가 아닌데 종을 치면 **다른 모든 플레이어에게 내 카드 1장씩** 줍니다.
- 내 덱의 카드를 모두 내면 탈락(테이블의 공개 카드는 종을 친 사람이 가져감), **마지막 1인이 우승**합니다.
  - 방장이 **[2명 남았을 때 게임 종료]** 를 켜면 두 명이 남는 순간 카드가 많은 사람이 우승합니다.

연타 방지를 위해 종을 친 직후 0.5~0.7초 동안은 다시 칠 수 없습니다.

## 4. 전국여행 마블 (3D) 규칙

도시를 사고 건물을 세워 통행료를 받는 **모두의마블 스타일 3D 보드게임**입니다. 서버가 주사위를 굴리고 판정하며, 화면은 3D로 결과를 연출합니다.

- **보드**: 28칸 (출발 · 도시 15 · 황금열쇠 4 · 세금 3 · 보너스 2 · 무인도 · 전국일주 · 무료주차)
- **인원**: 2~4명, 시작 자금 120만원, 출발지 통과 월급 20만원
- **매입/건설**: 도시 칸에 멈추면 매입, 내 도시에 다시 멈추면 **별장 → 빌딩 → 호텔**로 업그레이드
- **통행료**: 건물 단계에 따라 도시 가격의 10% · 25% · 50% · 90%
- **주사위**: 더블이면 한 번 더, **3연속 더블은 무인도행**
- **무인도**: 더블로 탈출하거나 3번 실패 후 보석금 15만원
- **황금열쇠**: 은행 이자·복권·생일 축하·기부·세무 조사·출발지 이동·무인도행 등 12장
- **파산**: 통행료를 낼 수 없으면 파산하고 도시는 채권자(또는 은행)에게 넘어갑니다
- **종료**: **15라운드**(대기방에서 10·15·20라운드로 변경)가 지나면 **총자산(현금+도시+건물)** 순위로 우승, 한 명만 남아도 종료

### 3D 보드 조작

- 보드를 **드래그**하면 시점이 돌아가고, **휠(또는 두 손가락)** 로 확대·축소합니다. **[🎥 시점 초기화]** 로 처음 시점으로 돌아옵니다.
- 주사위 2개가 중앙에서 굴러가 **서버가 정한 눈에 정확히 맞춰** 멈춥니다.
- 말은 **출석번호의 동물 색**을 그대로 쓰고, 칸을 하나씩 통통 튀며 이동합니다.
- 3D(WebGL)를 쓸 수 없는 기기에서는 같은 게임을 **2D 보드**로 보여 주므로 그대로 플레이할 수 있습니다.
- 보드는 **딥네이비·코지 우드 톤** 배경 위에 **아이보리 도시 카드 · 굵은 지역 색 띠 · 또렷한 한글 이름/가격/소유자 배지**로 그려져 멀리서도 잘 보입니다.

## 4-B. 새 게임 규칙 (숫자 줄세우기 · 오목 · 라이어 · 윷놀이 · 1인용 퍼즐)

### 🎯 숫자 줄세우기 (`#/streams`, 1~4명)
- 1~30 숫자 타일 30장 + 만능 조커(★) 2장을 섞어 **한 장씩 20장**을 공개합니다.
- 같은 숫자를 **모두가 동시에** 자기 **20칸 트랙**의 빈칸에 한 장씩 놓습니다.
- **이미 타일이 있는 칸만 빼고, 빈칸 20칸 어디에나 내 마음대로** 놓을 수 있습니다. (오름차순 칸을 강제하지 않음)
- 왼쪽은 작은 수, 오른쪽은 큰 수로 **이어지면 점수**. 조커(★)는 어디에나 놓이고 앞뒤 숫자를 이어 줍니다.
- 20칸을 다 채우면 끝나고, **끊기지 않고 이어진 가장 긴 구간**이 점수입니다.

### ⚫ 오목 (`#/gomoku`, 2명)
- 15x15 오목판, **흑이 먼저** 둡니다. 가로·세로·대각선 **5개를 먼저 이으면 승리**.
- 흑은 **금수(6목 이상 · 4-4 · 3-3)** 자리에 둘 수 없습니다. 백은 자유롭게 둡니다.
- 판이 가득 차면 무승부. 마지막 수에 표시가 남고, 이긴 줄이 빛납니다. AI 봇 연습·관전 지원.

### 🕵️ 라이어 추리게임 (`#/liar`, 3~6명)
- 주제(음식·동물·학교·직업·장소·놀이)를 방장이 고르거나 무작위로 정합니다. 한 명만 **제시어를 모르는 라이어**입니다.
- 순서대로 **힌트를 한 줄씩** 말하고(채팅 입력), 한 바퀴 돌면 **투표**합니다.
- 최다 득표자가 라이어면 → 라이어가 **제시어를 맞힐 마지막 기회**(보기 4개). 맞히면 라이어 승리, 틀리면 시민 승리.
- 라이어가 아닌 사람이 지목되거나 표가 갈리면 라이어 승리입니다.

### 🪵 전통 윷놀이 (`#/yut`, 2~4명)
- 윷가락 4개: **도 1 · 개 2 · 걸 3 · 윷 4 · 모 5 · 빽도 한 칸 뒤로**. 윷·모는 한 번 더 던집니다.
- 내 말이 있는 자리에 다른 내 말이 오면 **업기**, 상대 말이 있으면 **잡기**(출발점으로 보내고 한 번 더).
- 모서리(5·10번 자리)에 정확히 멈추면 **지름길**, 말이 모두 완주하면 우승. 말 개수는 방장이 2~4개로 정합니다.
- 윷판과 말은 3D로 그립니다. 윷가락 4개가 **던져져 구르다가 앞뒤가 정해져 멈추고**, 말이 말판 위를 한 칸씩 걸어갑니다. 화면을 드래그해 판을 돌려 볼 수 있어요.
- 3D(WebGL)를 쓸 수 없는 기기에서는 같은 게임을 **2D 윷판(SVG 29개 자리)** 으로 보여 주므로 그대로 플레이할 수 있습니다.

### 🧩 1인용 미니 퍼즐 (`#/puzzle`, 1명)
- **2048**: 방향키·WASD·스와이프로 숫자를 밀어 합칩니다. 2048을 만들면 승리, 더 못 움직이면 끝.
- **짝맞추기**: 8쌍(16장) 카드에서 같은 과일을 찾습니다. 적은 시도·짧은 시간일수록 점수가 높습니다.
- 최고점은 (반 코드 + 출석번호)별로 **이 기기에 저장**되고, 서버에 연결되어 있으면 **최고점을 갱신할 때 우리 반 포인트**가 조금 쌓입니다.

## 4-C. 2차 확장 게임 규칙 (숫자 타일 러미 · 도둑잡기 · 장기 · 컬러 숫자 카드 · 선 긋기 · 스도쿠)

### 🔢 숫자 타일 러미 (`#/rummi`, 2~4명)
- 타일은 **1~13 × 4색(빨강·파랑·노랑·초록) + 조커 2장**입니다.
- **같은 숫자 세트**(같은 숫자 다른 색 3~4장)와 **런**(같은 색 연속 숫자 3장 이상)을 만들어 테이블에 냅니다.
- **처음 등록**은 한 차례에 낸 타일 합이 기준 점수(기본 30점) 이상이어야 합니다. 대기방에서 **15점(수업용 간단)** 으로 바꿀 수 있어요.
- 조커는 한 세트에 1장까지 빈자리를 대신하고, 조커가 든 세트에는 타일을 더할 수 없습니다.
- 테이블 세트에 내 타일을 이어 붙일 수 있고, 낼 타일이 없으면 더미에서 1장 뽑습니다.
- **내 패를 먼저 다 내면 우승!** 더미가 비면 남은 타일 점수가 가장 낮은 사람이 우승입니다. (모둠 방 · AI 봇 연습)

### 🃏 도둑잡기 (`#/oldmaid`, 2~5명)
- 동물 짝 **12쌍(24장) + 도둑 카드 1장 = 25장**. 나눠 받은 뒤 같은 그림 짝은 자동으로 버립니다.
- 내 차례에는 **앞사람(왼쪽 친구)의 패에서 1장**을 뽑고, 짝이 맞으면 두 장을 버립니다.
- 손패를 먼저 털어낸 사람이 1등, **마지막까지 도둑 카드를 든 사람이 꼴찌**입니다. (모둠 방 · AI 봇 연습)

### ♟️ 전통 장기 (`#/janggi`, 2명)
- **9×10 장기판**, 초(아래)가 먼저 두고 한(위)이 이어 둡니다. 궁성(3×3)과 대각선이 있습니다.
- 차는 직선, **포는 다리 하나를 넘어야** 움직이고 포끼리는 잡지 못합니다. 마는 날일자, 상은 밭전자, 사·궁은 궁성 안, 졸·병은 앞과 옆으로 한 칸.
- **상대 궁을 잡으면 승리**, 상대가 둘 곳이 없으면(외통수) 승리. 내 궁이 공격받는 수와 두 궁이 마주 보는 수는 둘 수 없습니다. (모둠 방 · AI 봇 연습)

### 🎨 컬러 숫자 카드 (`#/onecard`, 2~5명)
- 4색 × 1~9 + 특수 카드(**점프 · 방향전환 · +2 공격**)를 색마다 1장씩 + **색 바꾸기 4장** = 52장. 한 사람 7장.
- 같은 색이거나 같은 숫자(또는 같은 특수 카드)를 냅니다. 점프는 다음 사람을 건너뛰고, +2는 다음 사람이 2장 뽑고 건너뜁니다. 색 바꾸기는 아무 때나 낼 수 있습니다.
- 낼 카드가 없으면 1장 뽑고 차례를 넘깁니다. **손패를 먼저 0장으로 만들면 우승.** (모둠 방 · AI 봇 연습)

### ✏️ 선 긋기 땅따먹기 (`#/dots`, 2~4명)
- **5×5 점(4×4 칸)** 보드에서 번갈아 선을 하나씩 긋습니다. (선 40개)
- 사각형의 **네 번째 선을 완성하면 그 칸이 내 땅**이 되고 **한 번 더** 그을 수 있습니다.
- 16칸을 모두 나누면 끝, **가장 많은 땅을 가진 사람이 우승**입니다. (모둠 방 · AI 봇 연습)

### 🔢 1인용 스도쿠 (`#/sudoku`, 1명)
- **4×4(저학년) · 6×6(중학년) · 9×9(고학년)** — 매번 **해답이 하나뿐인** 퍼즐을 새로 만듭니다.
- 메모(작은 후보 숫자)·힌트·오답 표시를 지원하고, 시간이 지나면 점수가 조금씩 줄어듭니다.
- 완성하면 점수와 함께 **이 기기에 최고 기록**이 저장되고, 서버에 연결되어 있으면 **우리 반 포인트**가 쌓입니다.

## 8. 서버 설정과 제한

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `HOST` | 0.0.0.0 | 바인딩 주소 |
| `GROUP_CAPACITY` | 4 | 모둠 방 정원 (최대 5) |
| `TEACHER_CREATE_CODE` | `easy` | 새 반을 만들 때 필요한 **교사 개설 암호**이자 제작자 통계(`#/admin`) 암호. 운영에서는 꼭 바꿔 주세요. |
| `CLASS_STORE` | `data/classes.json` | 만든 반(코드·이름·PIN 해시)을 저장하는 파일 |
| `UPSTASH_REDIS_REST_URL` | (없음) | Upstash Redis REST 주소. 토큰과 함께 넣으면 **반 목록 + 반별 랭킹을 Redis 에 영구 저장**합니다. |
| `UPSTASH_REDIS_REST_TOKEN` | (없음) | Upstash Redis REST 토큰 (비밀번호처럼 보관). |

- **반 목록은 파일에 저장**되어 서버를 다시 켜도 우리 반 링크가 살아 있습니다. PIN은 원문이 아니라 해시로만 저장합니다.
- **포인트 랭킹은 기본적으로 메모리에만** 보관합니다. 서버를 껐다 켜면 그 수업의 방과 **우리 반 포인트 랭킹은 초기화**됩니다. (학생 브라우저에 저장된 내 승수·포인트는 남습니다)
- **Upstash Redis 를 연결하면** 반 목록(PIN 해시)과 번호별 승수·포인트가 함께 저장되어, 서버가 재시작·절전에서 깨어나도 그대로 이어집니다. 환경변수가 없거나 Redis 가 잠시 안 되면 예전처럼 파일+메모리로 동작하고 콘솔에 경고만 남깁니다. (서버는 멈추지 않습니다)
- **나가기**를 누르면 자리가 실제로 정리되고, 사람이 한 명도 남지 않으면 봇만 남은 방은 자동으로 대기 상태(0/인원)로 돌아갑니다.
- 게임 중 연결이 끊긴 학생은 **자동 플레이(AI)** 로 바뀌어 게임이 멈추지 않습니다. 같은 창에서 새로고침하면 원래 자리로 돌아옵니다(토큰 재접속).
- **교사 관전과 방 초기화는 반 PIN 인증이 필요합니다.** 학생은 자기 반 방에 참가한 상태로는 초기화할 수 없습니다.
- AI 봇 연습은 서버 없이도 되고, 우리 반 안에서도 그대로 쓸 수 있습니다.
- 동시 접속 인원은 서버 PC 성능에 따라 다르지만, 여러 반(반당 6모둠 × 4명 = 24명) 규모도 무리 없이 처리합니다.

## 9. 인터넷에 올려서 쓰기 (배포)

### 8-1. 정적 링크 — GitHub Pages (첫 화면 · AI 봇 연습 · 규칙 안내)

- 주소: **https://easyteacher98-hue.github.io/-/**
- `public/` 폴더의 정적 파일만 올라간 `gh-pages` 브랜치를 Pages 소스로 사용합니다.
- GitHub Pages는 **파일만 전달하는 정적 호스팅**이라 WebSocket 서버를 돌릴 수 없습니다. 그래서 이 링크에서는 **첫 화면·AI 봇 연습·규칙 안내만** 동작하고, 반 코드 입장과 모둠 실시간 대전은 아래 Render 서버 링크에서 합니다.
- `public/` 을 고친 뒤 사이트에 반영하려면 아래 명령 한 줄로 `gh-pages` 브랜치를 다시 만듭니다(1~2분 뒤 반영):
  ```bash
  bash scripts/deploy-pages.sh            # origin 의 gh-pages 로 배포
  bash scripts/deploy-pages.sh --dry-run  # 푸시 없이 결과만 확인
  ```

### 8-2. 실시간 멀티플레이 — Render 무료 서버

1. 아래 원클릭 링크로 Render에 로그인(저장소의 GitHub 계정으로 로그인)합니다.
   **https://render.com/deploy?repo=https://github.com/easyteacher98-hue/-**
2. Render가 저장소 루트의 `render.yaml` 을 읽어 무료 Node 웹 서비스를 만듭니다.
   (`npm install --omit=dev` → `npm start`, 헬스체크 `/health`) — 테스트용 `jsdom` 은 설치하지 않아 배포가 빠릅니다.
3. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소가 나옵니다. 이 주소 하나로 **반 만들기 + 반 코드 입장 + 6모둠 실시간 대전 + 교사 관전 + AI 봇 연습**이 모두 동작합니다. 학생 기기(노트북·태블릿·휴대폰)에 이 주소나 우리 반 링크를 알려 주세요.
4. 무료 플랜은 **15분간 접속이 없으면 서버가 잠들고**, 다시 접속하면 깨어나는 데 약 1분 걸립니다(그동안 로딩 화면). 수업 중에는 접속이 이어져서 잠들지 않습니다. 무료 인스턴스 시간은 한 달 750시간이고, 그 달치를 다 쓰면 다음 달 1일까지 무료 서비스가 멈춥니다.
5. 무료 플랜의 디스크는 임시라서, 서버가 새로 배포되면 `data/classes.json` 이 사라질 수 있습니다. 반 목록과 랭킹을 오래 보관하려면 아래 **8-3 Upstash Redis(무료)** 를 연결하세요.

### 8-3. 무료 영구 저장 — Upstash Redis (선택)

Render 무료 서버는 15분 놀면 잠들고, 다시 배포하면 디스크가 비워집니다.
[Upstash](https://upstash.com) 의 **무료 Redis** REST API 를 연결하면 **반 목록(교사 PIN 해시 포함)** 과 **반별 번호별 승수·포인트 랭킹**이 서버 밖에 남아 그대로 이어집니다.

1. [upstash.com](https://upstash.com) 에 가입하고 **Redis → Create Database** 로 무료 DB 를 만듭니다(리전은 가까운 곳, 예: `ap-northeast-1`).
2. DB 상세 화면의 **REST API** 에서 두 값을 복사합니다.
   - `UPSTASH_REDIS_REST_URL` (예: `https://xxx-yyy-12345.upstash.io`)
   - `UPSTASH_REDIS_REST_TOKEN`
3. Render 대시보드 → 해당 서비스 → **Environment** 에 두 값을 추가하고 **Save** 합니다(자동 재배포).
4. 배포가 끝나면 `https://<서비스>.onrender.com/health` 에서 `"persistence":"upstash"` 가 보이는지 확인합니다.

로컬에서도 같은 환경변수로 바로 시험할 수 있습니다.

```bash
UPSTASH_REDIS_REST_URL="https://xxx.upstash.io" UPSTASH_REDIS_REST_TOKEN="..." npm start
```

- 저장 위치는 `halligalli:classes`(반 목록: 코드·이름·PIN 솔트/해시·생성일), `halligalli:classStats`(반별 번호별 `plays`·`wins`·`points`), `halligalli:gameStats`(게임별 플레이 수·1인용 최고점) 세 키입니다. **PIN 원문은 저장하지 않습니다.**
- 반을 만들거나 한 판이 끝나면 150ms 안의 변경을 모아 한 번에 저장하고, 서버가 종료될 때도 저장을 마치고 내려갑니다.
- Redis 가 잠시 안 되면 **복원이 성공할 때까지 저장을 미루고** 콘솔에 경고만 남깁니다(빈 목록으로 덮어쓰지 않음). 응답이 5초 넘으면 기다리지 않고 서버는 그대로 동작합니다.
- 설정을 빼면 예전처럼 `data/classes.json`(반 목록) + 메모리(랭킹)로 돌아갑니다. 기존 테스트·로컬 실행은 그대로입니다.
