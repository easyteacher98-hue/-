# 🔔 모둠 보드게임 (할리갈리)

모둠원이 각자 기기(태블릿·노트북·휴대폰)로 접속해 함께 즐기는 **실시간 보드게임 사이트**입니다.
첫 화면은 게임을 고르는 **포털**이고, 지금은 **할리갈리**를 플레이할 수 있습니다. (윷놀이는 준비 중)

- **6개 모둠 방**: 1모둠 ~ 6모둠이 기본으로 열려 있어, 방 코드를 만들 필요 없이 자기 모둠을 누르면 바로 입장합니다. (모둠당 4명 기준)
- **실시간 멀티플레이**: 방장이 시작하면 카드 뒤집기와 종 치기가 서버에서 동시에 판정됩니다.
- **귀여운 파스텔 디자인**: 크림·파스텔 색, 둥근 카드와 도톰한 버튼, 표정 있는 과일 그림, 닉네임별 동물 아바타(강아지·고양이·토끼·곰·여우·병아리).
- **종소리와 반짝임**: 종을 치면 흔들리는 애니메이션과 Web Audio 종소리('띠링~'), 정답/오답 색 피드백. **[🔔 소리]** 버튼으로 음소거할 수 있습니다.
- **교사 관전 모드**: 6개 모둠의 상태(대기/진행/종료), 참여 학생, 남은 카드, 현재 차례, 최근 이벤트를 한눈에 보고 원하는 모둠을 관전합니다. (관전자는 조작 불가, 막힌 방은 **[🧹 방 초기화]**)
- **방 나가기 · 게임 종료**: 게임판 위 **[🚪 방 나가기]** 로 실제 퇴장, 방장은 **[⏹ 게임 종료]** 로 대기실 복귀. 사람이 모두 나가면 모둠 방은 자동으로 0/4명 대기 상태가 됩니다.
- **다시 들어가기**: 모둠 목록으로 나와도 내 자리는 남아 있어 로비 카드의 **[다시 들어가기]** 로 바로 복귀합니다.
- **AI 봇 연습**: 서버에 접속하지 않아도 혼자서 4~5인 게임을 바로 해 볼 수 있습니다.
- **게임 규칙 안내**: 입장 화면과 대기방, 게임판 어디서나 규칙 모달을 열 수 있습니다.
- **폰트**: 제목·버튼은 배민 주아체(`Jua`), 본문은 고운돋움(`Gowun Dodum`) — 둘 다 OFL 무료 폰트이며, 폰트를 못 받아오는 오프라인 환경에서는 시스템 둥근 고딕으로 대체됩니다.

## 1. 실행 방법

Node.js 18 이상이 필요합니다.

```bash
cd halligalli-web
npm install        # 의존성 설치 (ws, jsdom(개발용))
npm start          # 서버 실행 (기본 포트 3000)
```

실행하면 터미널에 주소가 나옵니다.

```
내 컴퓨터 :  http://localhost:3000
같은 와이파이(모둠원) :  http://192.168.0.10:3000
```

학생 기기에서는 **같은 와이파이(같은 공유기)에 연결한 뒤** 두 번째 주소로 접속합니다.
포트를 바꾸려면 `PORT=4000 npm start`, 모둠 정원을 바꾸려면 `GROUP_CAPACITY=5 npm start` 처럼 실행합니다.

> 선생님 PC에서 서버를 켠 채로 수업이 끝날 때까지 두면 됩니다. 종료는 `Ctrl+C`.

### 인터넷이 없는 교실에서

`public/index.html` 파일을 브라우저로 직접 열어도 **AI 봇 연습**과 규칙 안내는 그대로 동작합니다.
(모둠 대전은 서버가 필요합니다.)

## 2. 수업에서 이렇게 사용합니다

1. 선생님 PC에서 서버를 켜고, 학생들에게 주소를 알려 줍니다.
2. 학생: **할리갈리 → 닉네임 입력 → 자기 모둠 번호(1~6모둠) 클릭** → 대기방 입장.
3. 대기방에서 친구들이 모이면 방장이 **[▶ 게임 시작]** 을 누릅니다.
   - 모둠원이 부족하면 **[🤖 봇 추가]** 로 인원을 채워 바로 시작할 수 있습니다.
   - **[📖 게임 규칙 보기]** 로 규칙을 함께 확인하세요.
4. 선생님: 첫 화면에서 **[교사 관전 모드]** → 6개 모둠 현황 확인 → **[👀 관전하기]** 로 특정 모둠 게임판을 실시간 관전.
5. 게임이 끝나면 결과 화면에서 방장이 **[다시 시작]** 을 눌러 한 판 더 할 수 있습니다.
6. 수업을 마칠 때는 학생이 **[🚪 방 나가기]** 를 누릅니다. 사람이 모두 나가면 모둠 방은 자동으로 대기 상태(0/4명)로 돌아와 다음 반이 바로 쓸 수 있습니다. 방장은 게임 중 **[⏹ 게임 종료]** 로 대기실로 돌아갈 수 있고, 선생님은 교사 관전 화면의 **[🧹 방 초기화]** 로 막힌 방을 정리할 수 있습니다.

> 브라우저 탭을 그냥 닫거나 와이파이가 끊긴 경우는 '나가기'와 다릅니다. 그 학생은 자동 플레이로 남아 게임이 멈추지 않고, 새로고침하면 원래 자리로 돌아옵니다.

| 규칙 보기 | **[📖 규칙]** |

## 3. 할리갈리 규칙 (구현된 정식 규칙)

- **카드 56장**: 과일 4종(딸기·바나나·라임·자두) × [1개 5장, 2개 3장, 3개 3장, 4개 2장, 5개 1장] → 과일당 14장
- 카드를 인원수(2~5명)에 맞춰 최대 1장 차이로 똑같이 나눕니다.
- 자기 차례에 자기 덱 맨 위 카드를 자기 앞에 1장 뒤집습니다. (차례는 자동으로 넘어갑니다)
- 테이블에 보이는 **모든 사람의 맨 위 카드**의 과일 개수를 합쳐, **어떤 과일이든 정확히 5개**가 되면 종을 칩니다.
- 가장 먼저 종을 친 사람이 **테이블에 공개된 카드를 모두** 가져갑니다. (덱 맨 아래에 섞여 들어감)
- 5개가 아닌데 종을 치면 **다른 모든 플레이어에게 내 카드 1장씩** 줍니다.
- 덱과 공개 카드가 모두 없어지면 탈락, **마지막 1인이 우승**합니다.
  - 방장이 **[2명 남았을 때 게임 종료]** 를 켜면 두 명이 남는 순간 카드가 많은 사람이 우승합니다.

연타 방지를 위해 종을 친 직후 0.5~0.7초 동안은 다시 칠 수 없습니다.

## 4. 파일 구조

```
halligalli-web/
├── server.js                 # HTTP 정적 서버 + WebSocket 방/좌석/관전 서버 (게임 공통)
├── package.json
├── README.md
├── public/
│   ├── index.html            # 앱 셸 (포털 → 게임 선택)
│   ├── engine.js             # ★ 할리갈리 규칙 엔진 (서버 Node.js와 브라우저가 함께 사용)
│   ├── css/style.css         # 전체 스타일 (모바일·PC 반응형)
│   └── js/
│       ├── app.js            # 라우터, 토스트, 모달, 공통 이벤트
│       ├── net.js            # WebSocket 연결/자동 재접속
│       ├── cards.js          # 표정 있는 과일 SVG·카드 렌더링
│       ├── avatars.js        # 닉네임별 귀여운 동물 아바타 SVG
│       ├── sound.js          # Web Audio 종소리·효과음 (음소거 기억)
│       ├── portal.js         # 첫 화면(게임 선택 포털)
│       └── halligalli.js     # 할리갈리 화면(입장·대기방·게임판·교사 관전·봇 연습)
├── src/
│   └── games/
│       ├── index.js          # 게임 레지스트리 (새 게임 등록)
│       └── halligalli.js     # 할리갈리 서버 모듈 (표준 게임 인터페이스)
└── test/
    ├── engine.test.js        # 규칙 엔진 단위 테스트
    ├── server.test.js        # WebSocket 방/관전/판정 통합 테스트
    └── ui.test.js            # jsdom 화면 테스트 (포털→입장→게임→관전)
```

규칙 계산은 **한 파일(`public/engine.js`)** 에만 있습니다. 서버(멀티플레이 판정)와 브라우저(AI 봇 연습, 화면 표시)가 같은 코드를 쓰므로 규칙이 어긋나지 않습니다.

## 6. 새 게임 추가하기 (확장 구조)

1. `src/games/<game>.js` 에 표준 인터페이스를 구현합니다 (`src/games/halligalli.js` 참고):
   `id, title, emoji, status, minPlayers, maxPlayers, defaultRooms(), createGame(), applyAction(), botTick(), serialize(), summary(), reasonText()`
2. `src/games/index.js` 의 `registry` 배열에 등록합니다.
3. `public/js/<game>.js` 에 화면을 만들고 `BG.router.add(...)` 로 경로를 등록한 뒤, `public/index.html` 에 스크립트 한 줄을 추가합니다.
4. `public/js/portal.js` 의 `BG.portalGames` 에 게임 카드를 추가합니다.

서버의 방·좌석·관전·전송 로직(`server.js`)은 게임과 무관하게 동작하므로 고칠 필요가 없습니다.
윷놀이는 `src/games/index.js` 의 `planned` 목록에 "준비 중"으로 등록되어 있습니다.

## 7. 서버 설정과 제한

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `HOST` | 0.0.0.0 | 바인딩 주소 |
| `GROUP_CAPACITY` | 4 | 모둠 방 정원 (최대 5) |

- 방 상태는 메모리에만 보관합니다. 서버를 껐다 켜면 방이 초기화됩니다(수업 중에는 끄지 마세요).
- **나가기**를 누르면 자리가 실제로 정리되고, 사람이 한 명도 남지 않으면 봇만 남은 방은 자동으로 대기 상태(0/인원)로 돌아갑니다.
- 게임 중 연결이 끊긴 학생은 **자동 플레이(AI)** 로 바뀌어 게임이 멈추지 않습니다. 같은 창에서 새로고침하면 원래 자리로 돌아옵니다(토큰 재접속).
- 교사 관전 모드에는 별도 비밀번호가 없습니다. 학교 내부망에서만 쓰거나, 필요하면 접속 비밀번호를 추가하세요. (교사 화면의 방 초기화도 같은 링크를 아는 사람이 쓸 수 있습니다)
- 동시 접속 인원은 서버 PC 성능에 따라 다르지만, 한 반(6모둠 × 4명 = 24명) 규모는 무리 없이 처리합니다.

## 8. 인터넷에 올려서 쓰기 (배포)

### 8-1. 정적 링크 — GitHub Pages (포털 · AI 봇 연습 · 규칙 안내)

- 주소: **https://easyteacher98-hue.github.io/-/**
- `public/` 폴더의 정적 파일만 올라간 `gh-pages` 브랜치를 Pages 소스로 사용합니다.
- GitHub Pages는 **파일만 전달하는 정적 호스팅**이라 WebSocket 서버를 돌릴 수 없습니다. 그래서 이 링크에서는 **AI 봇 연습과 규칙 안내만** 동작하고, 모둠 실시간 대전은 아래 Render 서버 링크에서 합니다.
- `public/` 을 고친 뒤 사이트에 반영하려면 아래 명령 한 줄로 `gh-pages` 브랜치를 다시 만듭니다(1~2분 뒤 반영):
  ```bash
  bash scripts/deploy-pages.sh            # origin 의 gh-pages 로 배포
  bash scripts/deploy-pages.sh --dry-run  # 푸시 없이 결과만 확인
  ```

### 8-2. 실시간 멀티플레이 — Render 무료 서버

1. 아래 원클릭 링크로 Render에 로그인(저장소의 GitHub 계정으로 로그인)합니다.
   **https://render.com/deploy?repo=https://github.com/easyteacher98-hue/-**
2. Render가 저장소 루트의 `render.yaml` 을 읽어 무료 Node 웹 서비스를 만듭니다. (`npm install` → `npm start`, 헬스체크 `/health`)
3. 배포가 끝나면 `https://<서비스이름>.onrender.com` 주소가 나옵니다. 이 주소 하나로 **6모둠 실시간 대전 + 교사 관전 + AI 봇 연습**이 모두 동작합니다. 학생 기기(휴대폰·태블릿)에 이 주소를 알려 주세요.
4. 무료 플랜은 **15분간 접속이 없으면 서버가 잠들고**, 다시 접속하면 깨어나는 데 약 1분 걸립니다(그동안 로딩 화면). 수업 중에는 접속이 이어져서 잠들지 않습니다. 무료 인스턴스 시간은 한 달 750시간이고, 그 달치를 다 쓰면 다음 달 1일까지 무료 서비스가 멈춥니다.
